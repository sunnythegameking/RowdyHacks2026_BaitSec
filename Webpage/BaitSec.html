Introducing... BaitSec

Keyword Search

When activated, starts a scan of all keywords on the site. Words such as “money,” “bitcoin,” and other words commonly used in scams.

Enforce HTTPS

When activated, automatically transfers your connection from HTTP to HTTPS. This allows for a more secure connection to the web.

Anti-Spoofing

If a web address is too similar to another popular address, BaitSec automatically denies going to the web address. (Ex: paypai.com)

How Does BaitSec Work?

New webpage = new scan

Extension scans URL -> sends to website checker

Website checker confirms if safe
